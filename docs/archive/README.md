# Archived Design Docs

These documents describe **earlier, pre-migration designs** of GlobePulse (the original
Streamlit/Databricks system and the plans that guided the move to the current
**React + FastAPI + Firestore + Gemini** stack). They are kept for historical context and
are **no longer accurate** for the running system.

For the current architecture, see [`../../ARCHITECTURE.md`](../../ARCHITECTURE.md).

| File | Original purpose |
|------|------------------|
| `data_pipeline.md` | Original Databricks-era data pipeline & sentiment ingestion notes |
| `agentic_transition_plan.md` | Plan to move to an agentic architecture (Google Antigravity) |
| `gcp_migration_plan.md` | Plan to migrate from Databricks to Google Cloud |
| `gmail_authorization_plan.md` | Plan for Gmail / Google OAuth authentication |
